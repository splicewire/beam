The operator's screens:
- `OperatorRegistry` gives read-only lists of agreements, versions and entries, each with its filter bar, and an
  optional coverage card.
- `PartyHistory` is one party's entries, narrowed by request parameters the host passes.
- `CoverageCard` draws a resource's summary through frame's summary card.

Each takes resource keys under the host's frame kit.

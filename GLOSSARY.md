# Glossary

- **Heading anchor**: the stable fragment identifier a docs heading carries, so a link can point at that heading.
- **Copy reference**: the reader-facing action on an anchored heading that puts the heading's link, as a URL or a Markdown
  link, on the clipboard.
- **Glossary term**: one named concept on the reader-facing docs glossary page, each its own anchored heading; distinct from a
  repository's `GLOSSARY.md` entry.
